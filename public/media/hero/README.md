Put Hero media files here:

- `source/hero-original.gif` - raw source for optimization
- `hero-bg.optimized.gif` - optimized GIF used by Hero section
- `hero-bg.webm` - lightweight video fallback (recommended)
- `hero-bg.mp4` - fallback for browsers without WebM support

Run optimization from project root:

```powershell
npm run optimize:hero-media
```
