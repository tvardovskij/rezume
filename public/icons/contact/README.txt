Put your contact icons here using these filenames:

- telegram.svg
- linkedin.svg
- github.svg
- vk.svg
- instagram.svg
- habr.svg
- email.svg

The contact section already points to `/icons/contact/<name>.svg`.
If an icon is missing, the UI falls back to a text monogram automatically.
Recommended: monochrome SVG on a transparent background, visually centered for a 24x24 icon box.
